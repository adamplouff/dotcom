You should probably be listening to Animalators by now because it's the incredible [@Zac Dixon](https://dribbble.com/zacdixon) talking with some really cool folks about design and animation. I really enjoyed getting the chance to chat about nerdy code things.

[Listen to Animalators](https://animalators.libsyn.com/episode-4-adam-plouff) (archive)

Each arm is built with two sets of hoses linked to an invisible hose group. Wonky setup, but it allows for drawing contours rather than filled shapes.
